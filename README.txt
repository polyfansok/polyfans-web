# Polyfans Web

Sitio comercial de Polyfans.

## Estructura

- `index.html` — página principal.
- `css/style.css` — diseño y responsive.
- `js/main.js` — menú móvil y galería.
- `img/trabajos/` — fotografías reales de trabajos.

## Antes de publicar

1. Cambiar el número de WhatsApp `5491123456789` por el número real.
2. Revisar el enlace de Instagram.
3. Reemplazar/agregar fotografías cuando quieras.
4. Abrir `index.html` para probar localmente.

## Publicación gratuita

El proyecto está preparado para subirlo a GitHub y desplegarlo en Cloudflare Pages.
